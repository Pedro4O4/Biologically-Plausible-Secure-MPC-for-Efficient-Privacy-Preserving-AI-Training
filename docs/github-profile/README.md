# Hi, I'm Pedro

B.Sc. Computer Science student specialising in **IT Security**: cybersecurity, digital forensics (DFIR) and
applied security research. I like practical, measured work over theory for its own sake.

## Current focus: bachelor thesis

**[Biologically Plausible Secure MPC for Efficient Privacy-Preserving AI Training II](https://github.com/Pedro4O4/Biologically-Plausible-Secure-MPC-for-Efficient-Privacy-Preserving-AI-Training)**

Does a spiking neural network trained with a local learning rule (STDP) really get cheaper under
Multi-Party Computation, once the cost of hiding data-dependent spike patterns is counted? I'm building the
full pipeline to answer that with measurements (MP-SPDZ), and a negative result is an acceptable answer.

- Done: from-scratch plaintext SNN (LIF + STDP + readout) on MNIST, 13 unit tests, an interactive local dashboard
- Next: secure baseline, secure SNN microbenchmarks, end-to-end prototype, leakage and cost analysis
